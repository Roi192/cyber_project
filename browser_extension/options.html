Website Monitor Collector

This extension sends only the domain and page path of websites you visit to your company's monitoring server. Query strings, fragments, cookies, form contents and page contents are never sent.

Generated once when the extension was installed. The extension cannot read the Windows computer name or user account, so the two fields below are plain labels you choose.

Only hosts listed in the extension's host_permissions can be used (127.0.0.1:5002 / localhost:5002).

DEV MODE: no API key configured - the server must also have API_KEY blank.
