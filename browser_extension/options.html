Website Monitor Collector

This extension reports only the website name and page path of the pages you open to your company's monitoring server. Query strings, fragments, passwords, cookies, form contents and page contents are never sent.

Ask whoever runs the monitoring server. It must start with http:// or https://. The browser will ask you to allow access to this server once.

Both are labels you choose. A browser extension cannot read the Windows computer or account name.

No API key saved. This only works if the server is in DEV MODE (API key disabled).
